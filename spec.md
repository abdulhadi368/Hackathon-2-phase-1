# Hackathon 2 – Phase 1

## Objective
Build an in-memory Python console app with basic CRUD functionality.

## Features

1. Add Item
   - Enter item name
   - Item stored in memory with unique ID

2. View Items
   - List all items with IDs and names
   - Shows message if no items

3. Update Item
   - Update item name by ID
   - Validates ID input (must be number)
   - Shows message if ID not found

4. Delete Item
   - Delete item by ID
   - Confirms deletion

5. Exit
   - Exit app safely

## Constraints
- No database or file storage; all data in memory
- Data resets on program restart
- Must be modular for future phases

## Tech Stack
- Python
- Console-based app

## Success Criteria
- Correct CRUD functionality
- Menu looping continuously until exit
