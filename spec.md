# Hackathon 2 – Phase 1

## Objective
Build an in-memory Python console app to manage items.

## Features
- Add Item
- View Items
- Update Item
- Delete Item
- Exit App

## Constraints
- No database or file storage
- Data resets on program restart

## Tech Stack
- Python

## Success Criteria
- Modular code
- Continuous menu loop
- Correct CRUD operations
