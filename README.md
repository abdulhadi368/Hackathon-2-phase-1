# Hackathon 2 – Phase 1

## Project: In-Memory Python Console App

This is Phase-1 of Hackathon 2. It implements **basic CRUD functionality** in a Python console app.

### Features

1. **Add Item**  
   - Add items with unique IDs.

2. **View Items**  
   - View all items with IDs and names.

3. **Update Item**  
   - Update item name by ID with input validation.

4. **Delete Item**  
   - Delete item by ID safely.

5. **Exit**  
   - Exit the application safely.

### Tech Stack
- Python (console-based)

### How to Run

```bash
python main.py
